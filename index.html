Practical Guide

Coding Agent Complexity Guide

Knowing this boundary is how you get the most out of the agent without wasting cycles.

✓  Great for the Agent

  • + New React component with props and tests
  • + Adding an API endpoint to existing route
  • + Refactoring a function to async/await
  • + Writing unit tests for a specific module
  • + Fixing lint errors and updating imports

✕  Keep for Yourself (for now)

  • - Restructuring your entire codebase
  • - Migrating REST to GraphQL
  • - Complex database migrations
  • - Implementing auth from scratch
  • - Multi-repo changes with cross-dependencies

The Important Slide

Security & Privacy

People always ask. Here's the full picture.

[?]

What Copilot Sees

  • Your open files and active editor context
  • Recently viewed files in your workspace
  • Code you paste into Chat
  • Your repository structure
  • That's it.
[→]

Where It Goes

  • Sent to GitHub's AI providers (OpenAI, Anthropic, Google)
  • Your code is NOT used to train models — default
  • Encrypted in transit and at rest
  • Prompts discarded after response is generated
[#]

Enterprise Controls

  • IP indemnification included
  • Content exclusion filters per repo/file
  • Audit logs for compliance
  • Org-level policy management
★ In the Copilot app, run /security-review on local changes before they land. Treat it as an additional check—not a replacement for code scanning, secret scanning, Dependabot, or human review.
Extensibility

MCP + Agent Plugins

MCP = Model Context Protocol — the USB-C port for AI. Build an MCP server once and it works with Copilot, Claude Code, Cursor, Windsurf, and any MCP-compatible tool.

Skills teach reusable instructions and workflows. MCP supplies tools and live context. Together they let agents follow your process and act on approved systems.

Agent Plugins 1.0: Package skills and MCP configuration once, then reuse the plugin across VS Code, Copilot CLI, the Copilot app, and the SDK. Enterprise policies can allow or block plugins, marketplaces, and MCP servers.

What MCP Unlocks

Query databases directly
Read telemetry and logs
Manage infrastructure
Connect to Jira, Slack, and more
Build custom internal tools
OAuth authentication supported

For Tool Builders

GitHub Copilot SDK

Programmatic access to the full agent stack — not just completions or chat. Agent mode, MCP tools, code review, all of it, available through code.

Copilot doesn't have to live inside an IDE. Think internal CLIs, automation pipelines, dashboards, CI/CD hooks. Anywhere you have a developer tool, you can embed Copilot.

Node.js Python Go .NET
Technical Preview — Start building today
issuecrush/server.js
const { CopilotClient } = await import('@github/copilot-sdk');

const client = new CopilotClient();
await client.start();

const session = await client.createSession({
  model: 'gpt-4.1',
});

const response = await session.sendAndWait({
  prompt: `Summarize this GitHub issue for triage...`,
}, 30000);

const summary = response.data.content;
await session.destroy();
await client.stop();

How to Use It Well

Best Practices

01

Review Everything

Copilot is your pair, not your autopilot. Always review generated code for correctness and security.

02

Give Great Context

Clear comments, descriptive variable names, relevant files open. Better input equals better output.

03

Break It Down

Complex problems become manageable when you feed Copilot smaller, well-defined tasks.

04

Use AGENTS.md

Share project-specific instructions to keep all agents in sync with your team's coding practices.

05

Start Simple

Begin with completions and chat. Then agent mode. Then the coding agent. Build confidence over time.

06

Custom Instructions

Define team standards in copilot-instructions.md so Copilot matches your conventions automatically.

Real Talk

Real Talk: Limitations

Knowing the edges makes you better at using it. Copilot is not magic.

Can't Read Your Mind

Copilot works from context: your code, your comments, your files. Vague input gets vague output.

Not a Compiler

Suggestions can contain bugs, incorrect logic, or hallucinated APIs. You are always the final reviewer.

Mirrors Your Patterns

If your codebase has bad practices, Copilot will suggest more of the same. Good code begets good suggestions.

Agent Has Boundaries

Best at low-to-medium complexity in well-tested codebases. Not ready for your gnarliest architectural refactors — yet.

You are the developer. Copilot is a powerful tool at your service — not the other way around.
